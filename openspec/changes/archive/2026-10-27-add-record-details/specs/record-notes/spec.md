# Spec Delta

## MODIFIED Requirements

### Requirement: 備考を記録の一覧に出す

ゲームは、記録の一覧の「新しい順」で、備考のある記録の行のすぐ下に、「難」の印と文を並べて出さなければならない（SHALL）。文は、書いたとおりの文字として出し、HTML として扱ってはならない（MUST NOT）。盤面ごとの並び（タイムの遅い順・速い順、ヒントの多い順）では、その盤面の記録に 1 回でも「難」の印があれば、盤面の行に「難」と出す。盤面ごとの並びの行には、備考の文と ✎ は出さない。備考の文は、盤面の欄を押したときの詳しい情報で、その回の下に出す（`record-details`）。

#### Scenario: 備考は、記録の行のすぐ下に、難の印と文を並べて出す

- **GIVEN** 8×8・ふつうの記録 3 件。一番古い記録に「難」と「左下で迷った」、真ん中は備考なし、一番新しい記録に文「サクサク」だけがある
- **WHEN** 「記録」を押す
- **THEN** 一覧は上から、新しい記録の行、「サクサク」の行、真ん中の記録の行、古い記録の行、「難 左下で迷った」の行の順に出る

#### Scenario: 備考の文字は、HTML として扱わない

- **GIVEN** 記録 1 件に、備考の文 `<img src=x><b>太</b>` がある
- **WHEN** 「記録」を押す
- **THEN** 行の下に `<img src=x><b>太</b>` という文字がそのまま出る
- **AND** 一覧の中に、img や b の要素はできない

#### Scenario: 盤面ごとの並びでは、難が付いた盤面の行に難と出す

- **GIVEN** 盤面 A の記録 2 件（古い方だけに「難」）と、盤面 B の記録 1 件（文「楽勝」だけ）がある
- **WHEN** 「記録」を押し、並びを「タイムの遅い順」にする
- **THEN** 盤面 A の行に「難」と出て、盤面 B の行には出ない
- **AND** 一覧には、備考の文「楽勝」と ✎ は出ない
