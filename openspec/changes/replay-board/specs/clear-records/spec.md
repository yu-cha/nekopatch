## MODIFIED Requirements

### Requirement: 記録を読み込む

ゲームは、「記録」の画面の「記録を読み込む」で、書き出したファイルの記録を、今の記録に足さなければならない（SHALL）。同じ記録（日時・盤面・難しさ・タイム・ヒントの回数が全部同じ）は 2 つにしない。「クリア ○ 問」の数は、ファイルの数に、今の記録のうちファイルに無いものの数を足した数にする。ただし、もう一度遊んだ記録（`replay-board` の「もう一度遊んだ記録」。読み込んだあとの記録で判断する）は足さず、今の数より減らさない。読めないところが 1 か所でもあるファイルは、何も読み込まず、今の記録を変えない（MUST）。

#### Scenario: 記録の無いブラウザで読み込むと、一覧・平均・ベストが元と同じになる

- **GIVEN** 記録が 40 件あるスマホで書き出したファイル
- **WHEN** 記録の無いブラウザで、「記録」を押し、「記録を読み込む」でそのファイルを選ぶ
- **THEN** 成績の表（回数・平均・ベスト・前回・平均ヒント）と、最近の記録の表が、書き出したスマホと同じになる
- **AND** 「クリア ○ 問」の数が、書き出したスマホと同じになる

#### Scenario: 同じ記録は 2 つにしない

- **GIVEN** 今の記録が A、B の 2 件で、ファイルの記録が B、C の 2 件
- **WHEN** ファイルを読み込む
- **THEN** 記録は A、B、C の 3 件になり、日時の順に並ぶ

#### Scenario: 同じファイルを 2 回読み込んでも、記録もクリアの数も増えない

- **GIVEN** あるファイルを読み込んだあと
- **WHEN** 同じファイルをもう一度読み込む
- **THEN** 記録の件数も「クリア ○ 問」の数も変わらない
- **AND** 「記録を読み込みました。同じ記録がもう入っていたので、増えた記録はありません。」と出る

#### Scenario: 新しいスマホで先に遊んだ分を、クリアの数に足す

- **GIVEN** 古いスマホで書き出した「クリア 800 問」のファイルがある
- **AND** 新しいスマホで先に 3 問クリアして、「クリア 3 問」になっている
- **WHEN** 新しいスマホで、そのファイルを読み込む
- **THEN** 「クリア 803 問」になる

#### Scenario: 読み込んでも、クリアの数は減らない

- **GIVEN** 「クリア 900 問」のスマホで、前に書き出した「クリア 800 問」のファイル（記録はすべて今のスマホにもある）
- **WHEN** そのファイルを読み込む
- **THEN** 「クリア 900 問」のまま

#### Scenario: 壊れたファイルを読み込んでも、今の記録は変わらない

- **GIVEN** 記録が 3 件ある
- **WHEN** 途中で切れた（JSON として読めない）ファイルを読み込む
- **THEN** 「このファイルは読み込めませんでした。今の記録はそのままです。」と出る
- **AND** 保存してある記録と「クリア ○ 問」の数は変わらない

#### Scenario: ねこパッチの記録でないファイルを読み込んでも、今の記録は変わらない

- **GIVEN** 記録が 3 件ある
- **WHEN** JSON として読めるが、ねこパッチの記録のファイルの印（`"format": "nekopatch-records"`）が無いファイルを読み込む
- **THEN** 「このファイルは読み込めませんでした。今の記録はそのままです。」と出る
- **AND** 保存してある記録は変わらない

#### Scenario: 一部だけ読めるファイルは、何も読み込まない

- **GIVEN** 正しい記録 2 件と、タイムが文字になっている記録 1 件が入ったファイル
- **WHEN** そのファイルを読み込む
- **THEN** 何も読み込まず、「このファイルは読み込めませんでした。今の記録はそのままです。」と出る

#### Scenario: 読み込んで増えた記録の数を知らせる

- **GIVEN** 今の記録が A の 1 件で、ファイルの記録が A、B、C の 3 件
- **WHEN** ファイルを読み込む
- **THEN** 「記録を読み込みました。増えた記録は 2 件です。」と出る

#### Scenario: 新しいスマホでもう一度遊んだ分は、クリアの数に足さない

- **GIVEN** 古いスマホで書き出した「クリア 800 問」のファイルがある
- **AND** 新しいスマホで、盤面 X を初めて 1 回と、もう一度 1 回クリアして、「クリア 1 問」になっている
- **WHEN** 新しいスマホで、そのファイルを読み込む
- **THEN** 「クリア 801 問」になる

### Requirement: 確かめ用のページは本物の記録を書き換えない

確かめ用のページ（`--mode trial` で作った版。`https://yu-cha.github.io/nekopatch/preview/` に置く）は、本物と同じ保存領域を使うので、保存のキーを `nekopatch-preview-` で始めなければならない（MUST）。本物のキーは読むだけにし、書いてはならない。

#### Scenario: 確かめ用のページは、最初に本物の記録を写して使う

- **GIVEN** 本物の記録 3 件と「クリア 812 問」が保存されていて、確かめ用のキーには何も無い
- **WHEN** 確かめ用のページを開く
- **THEN** 確かめ用のページにも、記録 3 件と「クリア 812 問」が出る
- **AND** 本物のキーの値は変わっていない

#### Scenario: 確かめ用のページは、本物のキーに書かない

- **GIVEN** 確かめ用のページを開いている
- **WHEN** 記録を読み込んだり、問題をクリアしたりする
- **THEN** 本物のキー（`nekopatch-v1`、`nekopatch-history-v1`、`nekopatch-boards-v1`）の値は変わらない
- **AND** 確かめ用の保存領域は、`nekopatch-preview-` で始まらないキーへの書き込みを止める

#### Scenario: 確かめ用のページには、確かめ用だと出す

- **WHEN** 確かめ用のページを開く
- **THEN** 「確かめ用のページです。ここで遊んだ記録や読み込んだ記録は、本物のねこパッチには入りません。」と出る
- **AND** 本物のページには、この文は出ない
