# Proposal

## Why

ナンは、難しかった盤面にリベンジしたり、同じ盤面でベストを更新したりしたい（ナン「同じ盤面をもう一度選んで遊びたい。盤面 ID の列を作り、『これを遊ぶ』で遊びたい。同じ盤面をもう一度遊んだら、前回とのタイムを比べたい。」）。

今のゲームは、盤面を乱数で作り、クリアしたら盤面の形を捨てる。記録には、日時・大きさ・難しさ・タイム・ヒントの回数しか残らない。

合意の全体は `docs/requirements-agreement-2026-10-23-replay-board.md`（2026-10-23）。

## What Changes

- クリアした盤面の形を、記録と一緒に残す。盤面には、形から決まる 5 文字の名前（盤面 ID。例 `K7Q2X`）をつけ、記録の一覧に出す。
- 記録の一覧の行ごとに「遊ぶ」ボタン、クリアの画面に「もう一度この盤面」ボタンを置く。何も置いていない盤面から、タイムもヒントも 0 で始める。遊んでいる途中なら、もう一度押してから始める。
- もう一度遊んだ記録は、成績の表（回数・平均・ベスト・前回・平均ヒント）と「クリア ○ 問」に数えない。
- もう一度クリアしたら、クリアの画面に、その盤面の回数・前回との差・ベストを出す。
- 「最近の記録」の表を「記録の一覧」にする。新しい順（1 回 1 行）のほかに、盤面ごとにまとめて、タイムの遅い順・速い順・ヒントの多い順に並べられる。大きさ・難しさで絞れる。30 件ずつ出し、「もっと見る」で増やす。
- 機種変更のときの書き出しのファイルに、盤面の形も入れる。前のファイルも読める。
- 「記録を全部消す」で、盤面の形も消す。

### ナンと確かめた細かいところ（2026-10-23）

- ① 盤面 ID を入力して遊ぶ欄は作らない。
- ② 盤面ごとの並べ替えは、その盤面のベストで並べる（例の「イ」）。リベンジに勝った盤面は、遅い順では下がる。
- ③ 「クリア ○ 問」は、もう一度遊んだクリアでは増やさない（ナンが「一般的にどうかでくろが決めて」と言い、くろが決めた）。
- ④ 今までの記録には盤面の形が無いので、もう一度は遊べない。成績には、初めての記録として数える。

## Capabilities

### New Capabilities

- `replay-board`: 盤面の形を残すこと、盤面 ID、記録の一覧とクリアの画面から同じ盤面を遊ぶこと、もう一度遊んだ記録の数え方と比べ方、記録の一覧の並べ替え・絞り込み・もっと見る、盤面の形の書き出し・読み込み・消去

### Modified Capabilities

- `clear-records`: 「記録を読み込む」で、「クリア ○ 問」に足す数から、もう一度遊んだ記録を除く

## 作らないもの（範囲外）

- 盤面 ID を入力して、その盤面を遊ぶこと（①）。
- 今までの記録（盤面の形の無いもの）の盤面を、作り直すこと。形が残っていないので、できない。
- 盤面を人に教える、ほかのスマホへ送ること（機種変更のファイルで移るだけ）。
- 難しさの差を大きくすること（ナンの質問への答えとして測ったが、作らない）。
- 遊びかけの盤面を、遊ぶ盤面を変えたあとに戻すこと。今の「新しい問題」と同じく、遊びかけは消える。
- 盤面ごとの並びの表で、日時の列を出すこと。

## Impact

- 保存データ: 新しいキー `nekopatch-boards-v1`（確かめ用は `nekopatch-preview-boards-v1`）を足す。`nekopatch-history-v1` と `nekopatch-v1` の名前と形は変えない（判断 490d、ff86）。
- 書き出しのファイル: `version: 1` のまま、記録の行に欄 `b` を足す（判断 490d）。
- 画面: 「記録」の画面の表と、クリアの画面のボタン。遊び方は変えない。
- 入れ替え: 今の版のタブが開いたままでも盤面の形は消えないが、その間のクリアには盤面が残らない。入れ替えの前に、ナンにねこパッチのタブを全部閉じてもらう。
