# Proposal

## Why

ナンは、難しかった盤面を LINE などで友だちに送り、同じ盤面で遊んでもらって、タイムを比べたい（ナン「他人と難しかった盤面コードなどをやりとりして（ラインとかで）、共有したい。」2026-10-25）。

今は、同じ盤面をもう一度遊べるのは、自分のスマホの中だけ。記録の一覧の 5 文字の盤面 ID は名前だけで、そこから盤面は作れないので、人に教えても遊んでもらえない。

合意の全体は `docs/requirements-agreement-2026-10-25-share-board.md`。

## What Changes

- 「この盤面を送る」ボタンを 3 か所に置く。クリアの画面、記録の一覧の行（「遊ぶ」の下）、遊んでいる途中（盤面の下のボタンの並びの「送る」）。
- 押すと、スマホの共有の画面（LINE やメールなどを選べる、スマホの機能）に、次のような文を渡す。共有の画面が無いブラウザでは、文を写して「写しました。LINE などに貼ってください。」と出す。
  ```
  ねこパッチの盤面 K7Q2X（8×8・ふつう）
  3:25・ヒント 0 回でクリア。挑戦してみて！
  https://yu-cha.github.io/nekopatch/?openExternalBrowser=1#n=8&d=2&b=…&t=205&h=0
  ```
  - 付けるタイムは、クリアの画面と「新しい順」の行ならその回、盤面ごとの行（タイムの遅い順など）なら初回のタイムとヒントの回数。
  - 遊んでいる途中に送るときは、2 行目を「これ解ける？」にし、タイムは付けない。
  - 盤面の形が無い前の記録の行には、「送る」を出さない。
- リンクの `#` より後ろに、盤面の大きさ・難しさ・盤面の形・タイム・ヒントの回数を入れる。`#` より後ろは、ブラウザがサーバーに送らないので、ページの中だけで読む。`?openExternalBrowser=1` は、LINE でタップしたときに、LINE の中のブラウザではなく、いつものブラウザ（Chrome）で開くための LINE の決まり。
- リンクを開くと、盤面の上に「送られてきた盤面」の案内（大きさ・難しさ、盤面 ID、送ってくれた人のタイムとヒントの回数、「この盤面を遊ぶ」「やめる」）を出す。遊びかけの盤面があれば、「遊ぶと、今の遊びかけの盤面はやめになります。」と書き添える。読めないリンクなら「このリンクの盤面は開けませんでした。」と「閉じる」を出す。案内を出したら、アドレスからリンクの中身を消す。
- 「この盤面を遊ぶ」で、送られてきた盤面を、何も置いていない状態から、時間もヒントも 0 で始める。大きさと難しさの選択も、送った人と同じにする。
- もらった盤面をクリアしたら、クリアの画面に「送ってくれた人（3:25）より 0:30 速い！」のように出す（秒の単位で比べる）。
- もらった盤面の記録は、今までどおり、初めての盤面なら成績の表と「クリア ○ 問」に数え、前に遊んだ盤面なら「もう一度遊んだ記録」にする。
- 記録の一覧（新しい順）で、もらった盤面の記録の行のすぐ下に「もらった盤面（送ってくれた人 3:25・ヒント 0 回）」と出す。
- もらった盤面の印を、記録とは別のキーに残す。機種変更の書き出し・読み込みにも入れ、「記録を全部消す」で一緒に消す。

### くろが決めた細かいところ

- ① 盤面の下のボタンの並びのボタンは、場所が狭いので「送る」とする。クリアしたあとに押したときは、クリアの画面の「この盤面を送る」と同じく、タイムを付ける。
- ② もらった盤面をクリアしたあと、「もう一度この盤面」で遊んだ回は、もらった盤面としない（自分で遊び直した回なので）。
- ③ 案内を出しているあいだは、時間を止める。「やめる」を押すと、続きから時間が進む。
- ④ ページを開いたままリンクを開いても（`#` の後ろだけが変わったとき）、案内を出す。

## Capabilities

### New Capabilities

- `share-board`: 盤面を送る文とリンクの作り方、送る場所、共有の画面と写すこと、リンクを開いたときの案内、もらった盤面のクリアの比べ、記録の一覧の印、もらった盤面の印の保存・書き出し・読み込み・消去

### Modified Capabilities

- `clear-records`: 「今までの記録を引き継ぐ」で、遊びかけの盤面の保存（`nekopatch-v1`）に足してよい欄に、もらった盤面の送った人のタイム（`received`）を加える

## 作らないもの（範囲外）

- 盤面の文字を貼って遊ぶ欄（ナンは「リンクをタップ」だけを選んだ）。
- iPhone（Safari）での確かめ（送る相手は Android の人だけ。ナンの答え）。
- 送る文に、送る人の名前、日時、備考を入れること。
- 遊んでいる途中に送るときに、置いた猫と × も送ること。
- 誰に、いつ送ったかを残すこと。
- 盤面ごとの並び（タイムの遅い順など）に、「もらった盤面」と出すこと。
- 友だちのタイムを、成績の表やランキングとして並べること。
- LINE のほかのアプリ（メールなど）に合わせた文の作り分け（同じ文を渡す）。

## Impact

- 保存データ: 新しいキー `nekopatch-received-v1`（確かめ用は `nekopatch-preview-received-v1`）を足す。`nekopatch-history-v1`、`nekopatch-boards-v1`、`nekopatch-notes-v1` の名前と形は変えない。`nekopatch-v1` には、リンクから始めた問題のときだけ、欄を 1 つ足す（判断 73b0）。
- 書き出しのファイル: `version: 1` のまま、もらった盤面の記録の行に、省いてもよい欄 `received` を足す。
- 画面: クリアの画面（「この盤面を送る」、送ってくれた人との比べ）、盤面の下のボタンの並び（「送る」）、記録の一覧（「送る」、「もらった盤面」の行）、送られてきた盤面の案内。遊び方は変えない。
- 通信: ページの決まり（CSP）は変えない。送るのは、ナンが押したときに、スマホの共有の画面に文を渡すだけ。
- 入れ替え: 今の版のタブでは、リンクを開いてもいつものゲームが出るだけ。入れ替えの前に、ナンにねこパッチのタブを全部閉じてもらう。
