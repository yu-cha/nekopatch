# ねこパッチ

猫を置いていくパズルです。ブラウザで遊べます。

**遊ぶ: https://yu-cha.github.io/nekopatch/**

## ルール

どの行・どの列・どの色のエリアにも、猫はちょうど 1 匹。猫どうしは縦・横・斜めにくっつけません。

## 中身

- TypeScript と Vite で作っています。ロジックは `src/core/`、画面は `src/ui/web/` にあります。
- GitHub Pages で、`gh-pages` ブランチ（ビルドしたもの）を公開しています。
- クリアの記録は、遊んだ人のブラウザ（localStorage）にだけ保存されます。どこにも送りません。
- 機種変更のときは、「記録」の画面の「記録を書き出す」でファイルにし、新しい端末の「記録を読み込む」で移せます。
