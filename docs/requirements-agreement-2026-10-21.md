# ナンとの合意（2026-10-21）: クリアの記録を長く残す

2026-10-21 のスレッドで、ナンと合意した要件の記録。合意した時点のまま残し、あとから書き換えない。

## 目的

- 数年ぶりに遊んでも、前のクリアの記録（タイム、前回との比べ、平均、ベスト）を見られるようにする。
- きっかけ: ナン「クリア記録、ずっと残せる？数年ぶりに遊んでも、前の記録見たい。」

## 使う人と場面

- ナンが、Android のスマホの Chrome で遊ぶ。2026-10-21 の時点で、ほかの機械では遊ばない。
- 機械ごとに記録が別々でよい（ナンの答え）。
- ゲームは公開のページ（https://yu-cha.github.io/nekopatch/ ）で、ナン以外の人も遊べる。
- ナンの今までの記録は、ナンのスマホの Chrome の中（localStorage の `nekopatch-history-v1`、`nekopatch-v1`）にだけある。

## 決まったこと

1. 記録は、スマホのブラウザの中だけに残す。ネットには何も送らない。スプレッドシートも使わない。
2. 新しい 500 回分しか残さない上限（今の `saveHist` の `slice(-500)`）をなくす。
3. ブラウザに、このゲームの保存領域を消さないよう頼む（`navigator.storage.persist()`）。空き容量が少ないときに、Chrome が長く開いていないサイトのデータから自動で消すのを防ぐため。
4. 頼みが通ったかどうかを、「記録」の画面に出す。通っていないときは、「ホーム画面に追加すると、記録が消えにくくなる」と案内する。
5. 機種変更のときだけ使う「記録を書き出す」（ファイルにする）と「記録を読み込む」を足す。ファイルを新しいスマホへ移すやり方は、そのときにくろが案内する。
6. 遊び方と見た目は変えない。

## ナンの手間

- 普段は何もしない。
- 案内が出たら、1 回だけ Chrome の「ホーム画面に追加」をする。
- 機種変更のときだけ、古いスマホで書き出す → ファイルを新しいスマホへ移す → 読み込む。

## それでも記録が消える場合（ナンに説明済み）

- Chrome の設定で「Cookie とサイトデータ」を消したとき
- Chrome を入れ直したり、スマホを初期化したりしたとき
- 記録を書き出さずに、機種変更したとき

## 検討して見送った案

- **記録を、ナン専用の新しい Google スプレッドシートへ自動で送る**: Apps Script のウェブアプリを窓口にして、送り先はナンのスマホのゲームにだけ入れる案。いったん「新しいスプシを作る」「機種変更の後はゲームの中で前の記録を見る」まで決めた。そのあと、ナンが「ネットに残さず端末に残して、手間のかからない方法がいい」と選び直した。
  - その前にナンは、「他の人の記録が自分のスプシに入るのは嫌」「スプシが公開されないか」「コードにスプシの情報が出てこないか」を心配していた。それぞれ、送り先を入れたナンのスマホだけが送ること、開くのは窓口だけでスプシは公開されないこと、コードにスプシの情報は出ないことを説明した。
- **ときどき「記録を保存」ボタンでファイルにする**: 押し忘れると残らないので、普段の方法としては見送った。機種変更のときだけ使う書き出しとして採用した（決まったこと 5）。

## くろの案（細かいところ。作るときにナンに確かめる）

- 今あるナンの記録を、作り直した後もそのまま読む。保存のキーを変えるときは、古いキーから引き継ぐ。
- すでに記録があるところへ読み込んでも、同じ記録は 2 つにしない。
- 読み込んだファイルが壊れている、または別のものだったときは、今の記録を変えずに、わかる言葉で知らせる。
- 書き出すファイルには、クリアの記録だけでなく、「クリア ○ 問」の数も入れる。

## できあがりの条件

- 501 回以上クリアしても、最初の記録が残っている（記録の一覧、平均、ベストに入る）。
- 頼みが通ったかどうかが「記録」の画面に出て、通っていないときに、ホーム画面への追加の案内が出る。
- 書き出したファイルを、記録の無いブラウザで読み込むと、記録の一覧、平均、ベストが元と同じになる。
- ナンのスマホで、今までの記録が消えずに残っている。
- ナンが Android の Chrome で確かめて、了承する。
