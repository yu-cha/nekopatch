# ナンとの合意（2026-10-25）: 盤面をほかの人と共有する

2026-10-25 のスレッド「ねこパッチ: 盤面をほかの人と共有する」で、ナンと合意した要件の記録。合意した時点のまま残し、あとから書き換えない。

## 目的

- 難しかった盤面を、LINE などで友だちに送り、同じ盤面で遊んでもらう。相手からも送り返してもらい、タイムを比べる。
- きっかけ: ナン「他人と難しかった盤面コードなどをやりとりして（ラインとかで）、共有したい。」（2026-10-25）
- 2026-10-23 の「同じ盤面をもう一度遊ぶ」の合意では、盤面 ID を入力して遊ぶ欄を「人に教える予定は無い」として見送った。今回、ナンの考えが変わった。

## 使う人と場面

- 送る人: ナン（Android のスマホの Chrome）。受け取った友だちが、送り返すこともある。
- 受け取る人: ナンの友だち。スマホは Android だけ（ナンの答え）。
- 送り方: LINE。

## 前提としてナンに伝えたこと

- 送れるのは、盤面の形が残っている記録だけ（2026-10-23 に「同じ盤面をもう一度遊ぶ」を入れてから遊んだ分）。それより前の記録（40 件ほど）は送れない。
- 記録の一覧の 5 文字の盤面 ID（`K7Q2X` など）は名前だけで、そこから盤面は作れない。盤面を送るには、盤面の形を文字にしたもの（8×8 で 32 文字）が要るので、リンクに入れて送る。
- LINE でリンクをタップすると、ふつうは LINE の中のブラウザで開き、相手の記録が Chrome とは別の場所に残ってしまう。リンクに LINE 用の印（`openExternalBrowser=1`。LINE の公式の仕組み）を付けて、Chrome などで開くようにする。

## 安全の面（ナンに説明した）

- ゲームは誰でも開けるページなので、受け取った人がリンクを転送すれば、その先の人も開ける。
- リンクに入るのは、盤面の形と、大きさ・難しさ、タイムとヒントの回数だけ。名前、日時、ほかの記録、備考は入らない。
- タイムを付けるので、相手にそのタイムが見える。
- ゲームのページは、外と通信しないように止めてある（CSP）。盤面はリンクの `#` より後ろに入れるので、GitHub のサーバーにも届かず、相手のスマホの中だけで読む。LINE には、ふつうのメッセージと同じく、送った文が残る。

## 決まったこと

ナンが「この内容で OK」と答えた。

### 送る

1. 「この盤面を送る」ボタンを 3 か所に置く。クリアの画面、記録の一覧の行（「遊ぶ」の横）、遊んでいる途中（盤面の下のボタンの並び）（ナンが 3 つとも選んだ）。
2. 押すと、スマホの共有の画面が出る。LINE を選び、相手を選んで送る。共有の画面が出せないときは、文を写して「写しました。LINE などに貼ってください。」と出す。
3. 届く文の例:
   ```
   ねこパッチの盤面 K7Q2X（8×8・ふつう）
   3:25・ヒント 0 回でクリア。挑戦してみて！
   https://yu-cha.github.io/nekopatch/?openExternalBrowser=1#…
   ```
   - 盤面と一緒に、タイムとヒントの回数も送る（ナンの答え）。
   - 付けるタイムは、クリアの画面と「新しい順」の行ならその回のタイム、盤面ごとの行（タイムの遅い順など）なら初回のタイム（ナンの答え。相手も初めて遊ぶので、同じ条件で比べられる）。
   - 遊んでいる途中に送るときは、まだクリアしていないので、タイムの代わりに「これ解ける？」と書く。
4. 盤面の形が残っていない前の記録は送れない。その行には「送る」を出さない。
5. 備考は文に入れない。言いたいことは、LINE で一言添える。

### 受け取る

6. 相手は、LINE のリンクをタップして開く（ナンの答え。盤面の文字を貼る欄は作らない）。Chrome でゲームが開き、こう出る:
   ```
   送られてきた盤面
   8×8・ふつう　K7Q2X
   送ってくれた人: 3:25・ヒント 0 回
   ［この盤面を遊ぶ］［やめる］
   ```
   - 遊びかけの盤面があるときは、「遊ぶと、今の遊びかけの盤面はやめになります。」と書き添える。「この盤面を遊ぶ」を 1 回押せば始まる。
   - 「やめる」を押すと、今の盤面のまま続けられる。あとで遊びたくなったら、もう一度リンクをタップする。
   - リンクが壊れていて開けないときは、「このリンクの盤面は開けませんでした。」と出し、いつものゲームを開く。
7. 何も置いていない盤面から、タイムもヒントも 0 で始まる。大きさと難しさは、送った人と同じになる。
8. クリアすると、いつもの比べる文に加えて「送ってくれた人（3:25）より 0:30 速い！」と出る。
9. もらった盤面の記録は、初めての盤面として、成績の表と「クリア ○ 問」に数える（ナンの答え）。前に遊んだことのある盤面（送り返された盤面など）なら、今と同じ「もう一度遊んだ記録」として扱う。
10. 記録の一覧のその行に「もらった盤面（送ってくれた人 3:25・ヒント 0 回）」と出す（ナンの答え）。
11. 受け取った人も、クリアの画面から自分のタイムを付けて送り返せる。
12. 機種変更のときの書き出し・読み込みに、もらった盤面の印も入れる。「記録を全部消す」では、印も一緒に消える。

## ナンの手間

- 送るときに、「この盤面を送る」を押して、LINE と相手を選ぶだけ。
- 受け取ったときは、リンクをタップして「この盤面を遊ぶ」を押すだけ。

## 検討して見送った案

- **盤面だけを送る、送るときに付けるかを選ぶ**: ナンは「タイムとヒントも送る」を選んだ。
- **リンクのほかに、盤面の文字を貼る欄を作る**: ナンは「リンクをタップ」だけを選んだ。
- **盤面ごとの行から送るときに、ベストのタイムを付ける（両方を付ける）**: ナンは初回のタイムを選んだ。
- **もらった盤面の記録を、成績の表と「クリア ○ 問」に数えない**: ナンは「数える」を選んだ。
- **もらった盤面だったことを、クリアの画面だけに出す**: ナンは「一覧にも残す」を選んだ。
- **iPhone でも確かめる**: 送る相手は Android の人だけ（ナンの答え）。

## できあがりの条件

- ナンが LINE で送ったリンクを、相手が Android のスマホでタップすると、同じ盤面を遊べる。
- 相手がクリアすると、ナンのタイムと比べた結果が出る。
- 相手が送り返したリンクを、ナンのスマホで開いて遊べる。
- ナンのスマホで、今までの記録が消えずに残っている。
- ナンが Android の Chrome で確かめて、了承する（確かめは、LINE の「Keep メモ」に送って、自分で開いてもらう）。
