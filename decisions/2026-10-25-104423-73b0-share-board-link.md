# 73b0 盤面を送るリンクは # の後ろに盤面とタイムを入れ、LINE の外のブラウザで開く印を付けて、スマホの共有の画面で送る。もらった盤面の印は別のキーに置く

## 結論

- 盤面を送るリンクの形: `<開いているページのアドレス>?openExternalBrowser=1#n=8&d=2&b=<盤面の符号>&t=205&h=0`
  - ページのアドレスは、開いているページの `origin + pathname`（確かめ用のページなら `…/nekopatch/preview/`）。
  - `#` の後ろは、名前付きの欄を `&` でつなぐ（`URLSearchParams` の形）。`n` は盤面の大きさ、`d` は難しさ（選んだ難しさ。記録の `d` と同じ）、`b` は盤面の符号（490d）、`t` は送る人のタイム（秒。画面の「3:25」と同じく切り捨て）、`h` はヒントの回数、`x=1` は送る人が「猫の周りに自動で×」を使って解いたこと（使ったときだけ付ける）。`t` と `h` は、両方あるか、両方無いか（遊んでいる途中に送るとき）。`x` は `t` と `h` があるときだけ付く。
  - `?openExternalBrowser=1` は LINE の決まり。LINE の中でリンクをタップしたとき、LINE の中のブラウザではなく、スマホのいつものブラウザで開く。ほかのアプリでは意味を持たない。
- リンクを読むとき: 欄 `n` と `d` が選べる値で、`b` から答えがちょうど 1 つの問題を作り直せて（`restorePuzzle`）、`t`（0〜359999）と `h`（0〜9999）が整数で、両方あるか両方無いかを確かめる。1 つでも外れたら「開けませんでした」と出す。知らない欄は無視する。読んだら、`history.replaceState` でアドレスから `?` と `#` の後ろを消す。開いているページの `#` だけが変わったとき（`hashchange`）も読む。
- 送り方: スマホの共有の画面（Web Share API の `navigator.share`）に、文だけ（`text`。リンクは文の最後の行）を渡す。共有の画面が無いか、出せなかったら（使う人が閉じたとき＝`AbortError` を除く）、文を写す（`navigator.clipboard.writeText`）。どちらもできなければ、送れなかったと出す。
- 送る文に入れるのは、盤面 ID、大きさ・難しさ、タイムとヒントの回数と自動×（ある場合）、リンクだけ。日時、備考、ほかの記録は入れない。
- もらった盤面の印は、記録とも盤面の形とも備考とも別の localStorage のキー `nekopatch-received-v1` に置く。形は `{"<記録の鍵>": {"senderTime": 205000, "senderHints": 0, "senderAutoX": true}}`（送った人のタイムはミリ秒。記録の `t` と同じ単位。`senderAutoX` は使ったときだけ）。タイムの無いリンクからの記録は `{}`。確かめ用は `nekopatch-preview-received-v1`。
- 遊びかけの盤面（`nekopatch-v1`）には、リンクから始めた問題のときだけ、欄 `received`（上と同じ形）を足す（c995 の `autoXUsed` と同じ考え。前の版は読み飛ばす）。
- 書き出しのファイルは `version: 1` のまま、もらった盤面の記録の行に `received` を足す。読み込みで同じ記録があれば、今のスマホにあれば今のまま、無ければファイルの方を使う。
- クリアの画面で送った人と比べるときは、秒の単位で比べる（画面に出るタイムどうしの差と同じにする）。

## 背景

- ナンとの合意（`docs/requirements-agreement-2026-10-25-share-board.md`）: 盤面とタイム・ヒントの回数を、LINE で送る。相手はリンクをタップして開く。クリアの画面、記録の一覧、遊んでいる途中から送る。受け取った人がクリアしたら、送った人のタイムと比べ、記録の一覧にも「もらった盤面」と残す。送る相手は Android のスマホ。
- 盤面は、符号（490d。6×6 で 16 文字、10×10 で 56 文字）から作り直せる。画面の 5 文字の盤面 ID からは作り直せない。
- ゲームのページは、CSP で通信を禁止している（privacy）。GitHub Pages で誰でも開ける。
- LINE は、トークのリンクを LINE の中のブラウザで開く。そこでの保存領域は Chrome と別なので、記録が分かれる。LINE の公式の説明（LINE ログインの「LINE URL スキーム」の「外部ブラウザで URL を開く」）では、URL の `?` の後ろに `openExternalBrowser=1` を付けると、外のブラウザで開く。`#` を含む URL について、説明には何も書かれていない。
- 今配信している版（c995 の版）は、備考のキーの知らない欄を読み飛ばし、備考を保存し直すときに落とす。

## 検討した選択肢

- 盤面をリンクのどこに入れるか:
  - **`#` の後ろ**（採用）: ブラウザはサーバーに送らない。LINE がリンクの見出しを作るために取りに行くときも、届かない。ページの中だけで読める。
  - **`?` の後ろ**: どのアプリでも残ることが確かだが、GitHub のサーバーと、LINE の見出し作りのサーバーに、盤面とタイムが届く。
  - **盤面の文字を貼る欄**: ナンが選ばなかった（リンクをタップするだけにする）。
- `#` の後ろの形:
  - **名前付きの欄**（採用）: あとから欄を足しても、今の版で開ける。人が見ても何の値か分かる。
  - **区切り文字で並べる（`#8.2.<符号>.205.0`）**: 10 文字ほど短いが、欄を足すと並びの意味が変わる。
- LINE の中のブラウザ:
  - **`?openExternalBrowser=1` を付ける**（採用）: LINE の公式の仕組みで、相手は何もしなくてよい。
  - **何もしない**: 相手の記録が LINE の中のブラウザに残り、Chrome で遊んだ記録と分かれる。
  - **画面で「Chrome で開き直して」と案内する**: 相手の手間が増え、ナンの友だちには分かりにくい。
- 送り方:
  - **スマホの共有の画面（`navigator.share`）**（採用）: Android の Chrome で使え、LINE を選べる。押した操作の中で出すので、勝手には送られない。
  - **文を写すだけ**: LINE を開いて貼る手間が増える。共有の画面が無いときの代わりにだけ使う。
  - **LINE の送る URL（`line.me/R/share?text=…`）に移る**: LINE だけに限られ、文が `?` の後ろに入って LINE のサーバーに届く。
- 共有の画面に渡すもの:
  - **文だけ（リンクは文の中）**（採用）: アプリによって、文と URL を別に渡したときの並べ方が違う。文だけなら、届く文が決まる。
  - **文と URL を別に渡す**: アプリによっては URL だけ、文だけが届く。
- もらった盤面の印の置き場所:
  - **別のキー `nekopatch-received-v1`**（採用）: 今の版のタブや戻した版が、記録や備考を保存し直しても消えない（490d、c995 と同じ理由）。
  - **備考のキー（`nekopatch-notes-v1`）に欄を足す**: 保存の処理は 1 つで済むが、今の版のタブで備考を書き直すと、その記録の印が消える。
  - **記録に欄を足す**: 490d と同じ理由で使えない。
- リンクのタイムの単位:
  - **秒**（採用）: 画面のタイムは秒までなので、比べた差が画面の数字の差と合う。
  - **ミリ秒**: 3 文字長いうえ、「3:25」どうしでも「0:00 速い」のような比べになる。

## 理由

- 合意の「相手はリンクをタップするだけ」を、LINE の中のブラウザに記録が分かれることなく、ページの通信の禁止（privacy）も変えずに満たせる。
- 送る文に入るものが決まっていて、個人の情報（名前、日時、備考）が入らない。
- もらった盤面の印は、今までの記録の形に触らず、今の版や戻した版が残っていても消えない。

## 影響・見直す条件

- LINE が `#` の後ろを落とすと、盤面が届かない。確かめ用のページで、ナンのスマホの LINE（Keep メモ）から開いて確かめる。落ちるなら、盤面を `?` の後ろに入れることを検討し、GitHub と LINE のサーバーに盤面とタイムが届くことをナンに説明する。
- 送ったリンクは、LINE に何年も残る。欄の名前と意味は変えない。変えるときは、新しい名前の欄を足し、前の欄も読めるようにする。
- リンクを知っていれば誰でも開ける。中身は盤面とタイムだけなので、困らない（ナンに説明した）。
- 前の版（この仕組みの無い版）でリンクを開くと、`#` の後ろは無視され、いつものゲームが開く。戻した版は `nekopatch-received-v1` に触らないので、もう一度入れ替えれば一覧の「もらった盤面」は戻る。戻した版のタブで遊びかけの盤面を保存し直すと、その問題の `received` だけが消える。
- iPhone（Safari）では確かめない（ナンの答え: 送る相手は Android だけ）。相手に iPhone の人が増えたら確かめる。
